## Not packaged

- **MEDA (Perseverance weather, PDS Atmospheres node)**: the archive host failed TLS from the build machine, so nothing was downloaded. `python3 -m marsdelta_pipeline meda` will ingest a MEDA CSV and its PDS4 label if they are placed in `data/raw/meda/`. Until then the weather card says the data is unavailable and shows no values.
- **Terrain model for the Nili Patera crop**: none is packaged, so no Nili bypass route is computed or offered.
